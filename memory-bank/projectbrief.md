# Project Brief: Personal Portfolio Website

## Core Requirements
- Modern, minimalistic design focusing on content and user experience
- Responsive layout that works well on all devices
- Fast loading and performance optimized
- Easy to maintain and update

## Goals
1. Showcase professional work and projects
2. Provide clear information about skills and experience
3. Make it easy for visitors to contact and connect
4. Demonstrate technical expertise through the website itself

## Key Features
- Home page with introduction and featured content
- Projects page with detailed project information
- Contact information and social links
- Blog section (coming soon)
- Community section (coming soon)

## Technical Stack
- Next.js for the framework
- TypeScript for type safety
- Tailwind CSS for styling
- Shadcn UI for components
- Lucide React for icons
